1ST GEAR · PHYSICS PROJECT

The gearbox you're driving.

A four-speed manual gearbox, 3D-printed and driven by a small electric motor, built to show how gear ratio sets output speed. I counted output rotations for a minute in every gear: 20, 53, 73 and 110. The same numbers became my maths project on ratio and proportion.

HOW I WORK

Questions first, then something I can measure.

01

Ask a real question.

For the Mercedes hackathon I asked whether a 1.0 L turbo petrol engine could stand in for a 1.5 L naturally aspirated one in India, then built a physics simulation to compare them.

02

Build something I can hold.

A printed gearbox, a printed drone frame, a heated test rig. If I can hold it, I can test it.

03

Let the numbers argue.

20, 53, 73 and 110 rotations a minute, counted in each gear. The numbers on this page come from the real build.
